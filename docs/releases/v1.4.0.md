JAM 1.4.0 adds the persistent tier: one global install puts a `jam` command on
the machine, and everything it runs still goes through the runtime selection a
user already made. It also carries the Windows DPAPI credential-store fixes.

## What changed

- **Persistent path (B2)** — `npm install -g @jam-mcp/launcher` provides `jam`
  as an optional short command; nothing else changes (not the editor wiring,
  not a shared `.mcp.json`, not a teammate who never installed it).
- **Windows DPAPI store** — three fixes around argv contract and encoding for
  the file-based credential store encrypted to the user account.
- Lockstep version bump across the three packages.

## Install / Upgrade

```bash
npx --yes @jam-mcp/bootstrap@1.4.0 init
```

Optional persistent command:

```bash
npm install -g @jam-mcp/launcher@1.4.0
```

Existing bindings, runtime selection and credentials are untouched.

## Agent setup

No change to the canonical entry:

```bash
npx --yes @jam-mcp/bootstrap@1.4.0 setup --agent
```

## Compatibility

- Node 20 or newer, unchanged. The five-tool MCP surface is unchanged.
