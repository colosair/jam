WHAT THIS FILE IS
-----------------
A structured, anonymised record of the measurements reported during the live
comparison session. The original terminal transcript was not preserved, so
this is a reconstruction of the reported figures, not a copy of raw output.
See evidence-manifest.md for exactly what this does and does not establish.

All identifiers are placeholders: PROJECT for the Jira project key,
PROJECT-101 style for issue keys, CURRENT_USER for the account, and
https://example.atlassian.net for the site. Issue summaries are deliberately
omitted.
